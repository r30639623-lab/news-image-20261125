A newspaper front page summing up Wednesday 25 November 2026's world news in
one image: 35 stories across 7 regions — Shenzhou 24 lifting off with
Pakistan's first astronaut, Gukesh taking White in Game 2 of the chess title
match in Geneva, nine Champions League ties lighting up Wednesday evening,
and the rest of the day's news, every story dated 25 November 2026. The
image is drawn with Pillow (`render.py`); `main.py` copies it to
`$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To re-render the image from scratch:

```sh
python3 render.py
```
